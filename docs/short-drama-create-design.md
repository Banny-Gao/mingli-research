## 1. 目标

创建交互式使用 MiniMax H3 创作短剧的 Claude Code skill:

1. 开始一部剧只需要想法,只定整体框架
2. 每一集根据框架与前面剧情再定具体内容
3. 每部剧资源跟着剧集管理,多部剧之间可共享资源(跨剧共享 v1 仅登记不强制,已确认接受)
4. 创作证据留存(复盘回放)
5. 正式视频生成前做足够前置校验,降低单条视频重做率

## 2. 调研要点(2026-08-03)

- mmx CLI 仅封装旧版 Hailuo-2.3,**不支持 H3** → 全部原生 HTTP API
- H3 为异步任务制:`POST /v2/video_generation` → 轮询 `/v2/query/video_generation/{task_id}`
- 模式:t2va(文生)/ i2va(首帧/尾帧/首尾帧图生)/ **r2va(多模态参考:参考图≤9 + 参考视频≤3 + 参考音频≤3)**;`reference_*` 与 `first_frame/last_frame` **互斥**
- ratio 行为分模式:t2va 必填且不能 adaptive;i2va 强制 adaptive(由输入图决定);r2va 默认 adaptive(由参考图决定)
- H3-Context-IR(`/v2/h3_context_ir`):增强提示词(三段式:分镜/环境音/配乐),不生成视频,按 token 计费
- video_regeneration:768P → 2K(须**原样提交**原始输入 + **最终 prompt**);base_video 规格:必须含音轨、24fps、宽高被 32 整除、面积≤768×1344、总帧数 107-362 且**每档递增 17 帧**(107/124/141/…/362)
- 任务管理:query/list 仅最近 7 天;delete 按状态(queued 取消/running 不可操作/succeeded·failed·cancelled 删除);回调需 3 秒内回应 challenge
- 文件上传:`mm_file://{file_id}`,有效期 7 天;图≤30MB / 视频≤50MB / 音频≤15MB;参考音频**每段 2-15s、总时长 ≤15s**
- 图像:image-01 / image-01-live,i2i 支持 `subject_reference(type=character)`,n≤9,seed **近似**复现(非精确)
- 语音:speech-2.8-hd 等,同步 ≤10k 字符,emotion(9 种),字幕时间戳;**无 duration 参数,时长由文本长度决定**
- 音乐:music-3.0(歌词/纯音乐);cover 是**独立模型** music-cover
- 文本:MiniMax-M3(1M 上下文)
- 视觉:**无公开 REST 接口**(mmx CLI 的 vision describe 与 Token Plan 的 understand_image 均不可依赖)→ 抽帧审用 **Claude 原生视觉**
- 异步长文本 T2A(100 万字级)、音色克隆/设计需企业认证 —— **未证实**(相关页面 404),v2 内容,标注待核实
- 教程附录 B 的 `minimax_h3.H3Client` **不存在**(LLM 幻觉),只有 HTTP API
- H3 视频按量计费,无公开单价;官方定价页确认**视频资源包暂不支持 H3** —— 单价以实测为准,可配置常量兜底

## 5. v1 范围(在范围内)

- 状态机:想法确认 → 整体框架 → **选 voice_id** → 角色圣经+声音圣经 → **资产验收**(角色 LLM 审+人工/声音仅人工听)→ **黄金锚+定稿锁** → 单集剧本 → 分镜表 → 本集场景/道具资产 → **前置校验**(含 file_id 有效性)→ **成本 gate** → **样镜子循环** → Context-IR 增强(意图校验+fallback)→ r2va 出片 → **成片验收**(黄金锚+跨镜+人工听声)→ 按因分流重试(熔断)→ **regeneration 2K**(可选,独立 gate)→ 2K 抽验 → **集级复盘**
- 补丁模式:受影响面计算表;角色外貌改动须确认废弃成本;声音锚重生成触发条件
- 本剧内共享资产(跨集复用)
- 证据:结构化 log 追加,含成本(`usage`)与失败原因;请求快照保存
- 前置校验:完整性/一致性/可生成性(含同框约束、i2va 规则、ratio 规则、文件规格、file_id 有效期)
- 成本:批量出片前预估 gate + regeneration 独立 gate + 重试熔断(3 次)+ 集级预算熔断
- 768P 草稿 → regeneration 2K(可选开关,流程化)
- 版权:所有参考图禁用真人/明星脸

## 6. v2 展望(不在 v1 范围内)

### A. 后期剪辑(最大的 v2 块)
- EDL 生成(剪辑决策表 JSON)
- ffmpeg 机械剪辑(拼接/切帧/转场/慢动作/多平台导出/封面)
- 字幕(SRT 生成与烧录)
- BGM(music-3.0 按 Context-IR 配乐提示生成 + 混音 ducking)
- 整集成片输出
- 整集统一配音替换兜底(固定 voice_id TTS 换 H3 音轨)—— **若 §0 假设验证失败,提前到 v1**

### B. 角色一致性进阶
- 同框戏方案(单人镜头 + ffmpeg 拼接 / V2V 加人 / 多人 reference)
- 后期人脸修复集成(FaceFusion / Reactor)
- LoRA 角色专属模型训练(长剧/矩阵号才划算)

### C. 质量与效率增强
- 失败学习闭环(v1 已记录单镜失败原因,但跨剧沉淀为"什么提示词爱失败"知识库 → v2 才值得建)
- 批量自动化(多镜并行、批量抽帧自动审、自动重试循环)
- callback_url webhook(替代轮询)
- 异步长文本 T2A(100 万字级,整集配音场景;企业认证/接口能力待核实)

### D. 流程/产品化
- 自由指令模式 / 双轨入口
- 跨剧共享 manifest 完整机制(登记/查询/引用/复制)
- 发布与数据复盘(平台规格/标题封面/多平台分发/完播率)
- 工业化批量生产(10 集流水线/矩阵号/商业化)
- 音色克隆 / 音色设计(需企业认证,能力待核实)

## 7. 流程链路脑图

```
0. 想法 Idea
   ├─ 输入:题材偏好 / 目标受众 / 情绪钩子 / 集数规划
   └─ GATE:确认想法

1. 整体框架 series.md ── 每部剧唯一框架源
   ├─ 一句话核心冲突 / 主角设定 / 分集主线 / 爆款指数
   └─ GATE:框架确认
       └─ [补丁] 改框架 → 受影响面计算 → 只重生成受影响下游

2. 角色圣经 + 声音圣经 ── 剧级资产,一次投入全剧复用
   ├─ 为每角色选 voice_id ⭐(系统音色;克隆/设计音色留待认证后)
   ├─ 文生图 image-01 → 角色参考图(核心锚/表情锚/服装锚)
   ├─ TTS → 声音锚 ⭐ A 轨锚:按情绪分档(中性/哭/怒/惊,每段 ≥2s)
   │    └─ 锚文本:LLM 按人设写"角色标志性台词集",与剧本解耦
   ├─ B 轨 ⭐:每镜台词用固定 voice_id 的 TTS 合成确定性对白(存本集 assets/)
   ├─ 版权检查:禁用真人/明星脸
   ├─ 校验:规格校验(文件/比例/大小/9:16)
   ├─ 资产验收 ⭐:角色 = LLM 审(脸)+ 人工;声音 = 仅人工听
   ├─ 挑最佳 → 黄金锚(每角色 1 张,后续所有验收基准)
   └─ 定稿锁 LOCKED ⭐(改外貌须确认废弃成本)
       └─ GATE:角色一致性人工确认

3. 单集剧本 episode.md ── 基于框架 + 前面剧情
   ├─ 输入:框架 + 前情提要(读已完成集)
   ├─ 结构:开篇钩子 → 冲突建立 → 升级对抗 → 结尾钩子
   ├─ 迭代:自由对话不限轮(每轮改一个维度)
   ├─ 短剧感自检 ⭐(钩子强度/转折密度/台词口语化/结尾钩子)
   └─ 证据:每次产出自动追加 evidence/log
       └─ GATE:剧本确认

4. 分镜表 ── episode.md 内(字段以 §8 为准)
   ├─ 拆解:5 分钟 ≈ 25-30 镜 / 每镜 4-15s
   ├─ 每镜:镜号/场景/人物/动作/台词/镜头语言/光影/音效/时长/模式/
   │       优先级/声音锚(情绪段)/动作接续/比例(9:16)/分辨率/状态
   ├─ 声音锚引用:按台词情绪选段 ⭐
   ├─ 同框约束 ⭐:有台词角色 ≤ 3;i2va 仅无台词镜头
   └─ 状态字段 ⭐:待生成/已生成/验收中/PASS/FAIL(原因)(文件即状态)
       └─ GATE:分镜确认

5. 本集资产生成
   ├─ 场景参考图(文生图,无人空镜,统一 9:16)
   ├─ 道具 / 服装锚
   └─ 校验:规格校验

6. 前置校验 ⭐(需求 5:降重做率)
   ├─ 完整性:每镜字段齐全 / 台词匹配角色 / 声音锚引用有效
   ├─ 一致性:角色 ref 全部引用 / 服装场景引用齐全 / 同框约束满足
   ├─ 可生成性:参考图文件存在 / 文件≤规格 / 时长比例合法 /
   │           i2va 无台词 / ratio 按模式 / 参考音频 ≤3段·每段2-15s·总≤15s
   ├─ file_id 有效性 ⭐:7 天过期则重传并更新引用
   └─ GATE:人工确认 ready → 才开始生成

7. 成本预估 gate ⭐(每批,非每镜)
   ├─ 本批镜头数 × 时长 × 单价(768P/2K 实测值,可配置)
   ├─ 已用预算(本集/本剧)+ 重试熔断(每镜 ≤3 次)+ 集级预算
   └─ 确认后才生成

8. 样镜验证 ⭐ 子循环(每集首个 P0,走完整链路)
   └─ 选首个 P0 → Context-IR 增强 → 生成(768P)→ 验收
       ├─ 验收项:黄金锚对比 / 提示词风格 / 一致性 /
       │         锁声实测 ⭐(音色一致?未复读锚文本?台词内容正确?)
       ├─ 通过 → 定质量基线 → 批量铺开
       └─ FAIL → 调提示词/资产;锁声失败 → 回决策层(§0 对策)

9. Context-IR 提示词增强(每镜)
   ├─ 输入:分镜 + 参考图/音频
   ├─ 输出:三段式增强提示词(分镜描述/环境音/配乐)
   ├─ 意图校验 ⭐:LLM 确认忠实原分镜(镜头/台词/人物不变)
   ├─ fallback ⭐:失败/超时/跑偏 → 手动模板写提示词
   └─ non_diegetic_music ┄┄(存证据,供 v2 BGM)

10. r2va 视频生成 ⭐(出片核心)
    ├─ 有声对话镜:必带 reference_image 锁脸 + reference_audio 锁声 ⭐(A 轨)
    ├─ t2va 空镜:仅文本(不带参考图,防污染)
    ├─ i2va 无台词镜:仅首帧图 + 文本(不带音频锁)
    ├─ B 轨 ⭐:每镜台词 TTS 合成确定性对白(固定 voice_id),存本集 assets/audio/
    ├─ 可选:reference_video 前镜成片(动作接续)
    ├─ 流程:创建任务 → 轮询 → 下载落盘 shots/(v0/v1/...)
    ├─ 请求快照保存 ⭐(完整请求体 → 供 regeneration/补丁复用)
    ├─ 任务管理:list/delete(7 天窗口)
    └─ 版本命名:shot_XX_v{NN}.mp4(补丁/重试递增)

11. 成片验收 ⭐
    ├─ LLM 抽帧审(Claude 原生视觉):黄金锚对比 / 服装 / 标志 / checklist
    ├─ 跨镜对比 ⭐:带上 1-2 张已 PASS 前镜帧,检查"同一人"
    ├─ 人工听声 ⭐:对白清晰/音画同步/音效/音色漂移
    ├─ B 轨对比 ⭐:A 轨(H3 自带)音色/台词 vs B 轨(TTS 确定性)音频
    │    A 轨不合格 → 单镜用 B 轨音频替换音轨(ffmpeg,单文件,非剪辑)
    ├─ 人工确认 → PASS → 分镜表状态更新 + 入 evidence
    └─ FAIL → 按因分流重试(每镜 ≤3 次)
        ├─ 提示词问题 → 改提示词 → 回 9
        ├─ 参考图问题 → 修资产 → 回 2/5
        ├─ 敏感内容 → 改描述 → 回 9
        ├─ 规格问题 → 修参数 → 回 10
        └─ 音频/音色问题 ⭐ → 检查锚与台词 → 回 2/3/9
     证据:失败原因入 log(复盘回放)

12. regeneration 2K ⭐(可选开关,本批全部 PASS 后)
    ├─ 触发:本批全部 PASS 且启用 2K
    ├─ 规格预检 ⭐(ffprobe):音轨存在 / 24fps / 宽高被 32 整除 /
    │            面积≤768×1344 / 帧数∈{107+17k}
    │            不满足 → 真实选项:时长裁剪(接受风险)/ 放弃该镜 regen / 重生成
    ├─ 2K 成本 gate(独立,区别于草稿成本)⭐
    ├─ 提交(原样输入 + 最终 prompt,768P 不二次编码)→ 轮询 → 落盘
    └─ 2K 抽验 ⭐(轻量:黄金锚 + 关键帧 + 人工瞄一眼)

13. 集级复盘 ⭐(每集收尾)
    ├─ 成本汇总(本集/累计,含 regeneration)
    ├─ 重做率(FAIL 次数/总生成次数)
    ├─ 失败镜头分布(原因分类,含音频/音色类)
    └─ 经验教训 → 入 evidence(供 v2 学习闭环)

14. 剪辑 ┄┄ v2 展望
    ├─ EDL 剪辑决策表(节奏/转场/黑场)
    ├─ ffmpeg 拼接 / 切帧 / 字幕烧录 / 转场
    ├─ BGM:music-3.0 按配乐提示生成 + 混音 ducking
    ├─ 整集统一配音替换兜底(TTS)
    └─ 多平台导出 / 封面抽帧
```

> v1 实线,`┄┄` 为 v2 展望。补丁模式:任意上游改动 → 受影响面计算 → 只重做受影响下游;角色外貌改动须先确认废弃成本。

## 8. 关键数据结构

### 分镜表(episode.md 内,Markdown 表格或 CSV)

| 字段 | 说明 |
|---|---|
| 镜号 | shot_01, shot_02, ... |
| 场景 | 引用本集或共享场景资产 |
| 人物 | 角色 id(引用角色圣经) |
| 动作 | 具体动作/微表情 |
| 台词 | 该镜对白(中文原文,与角色绑定) |
| 镜头语言 | 特写/中景/远景/俯拍/跟拍 |
| 光影 | 光源/色调/氛围 |
| 音效 | 环境音/SFX 提示 |
| 时长 | 4-15 整数秒 |
| 模式 | r2va(有声对话)/ t2va(空镜)/ i2va(无台词) |
| 优先级 | P0(开场/反转/结尾)/ P1(普通对话)/ P2(空镜/远景) |
| 声音锚 | 引用的角色声音锚(按情绪段,如 林念安·怒) |
| 动作接续 | 是否引用前镜成片作 reference_video(可选) |
| 比例 | 默认 9:16;t2va 必填;r2va/i2va 按模式规则 |
| 分辨率 | 768P(草稿)/ 2K(regeneration 后);默认 768P |
| 状态 | 待生成/已生成/验收中/PASS/FAIL(原因)/2K 已抽验 |

### 镜头生成请求快照(evidence/ 下,JSON)

每镜生成时保存完整请求体:`{model, content[], resolution, duration, ratio, 最终prompt, 参考资产路径, file_id 引用}`——regeneration 与补丁复用,防止"原样提交"要求丢失。

### 受影响面计算表(补丁模式,rules/validation.md)

| 变更类型 | 影响范围 | 处理 |
|---|---|---|
| 改台词 | 该镜重生成;声音锚文本与台词脱节 → 重生成该镜声音锚(如情绪段无匹配则重建) | 重做该镜 |
| 改场景 | 引用该场景的全部镜头 | 重做 + 场景资产重建 |
| 改道具 | 引用该道具的镜头 | 重做 |
| 改角色外貌 | 该角色全部已出镜头作废 + 相关声音锚 | 先确认废弃成本 |
| 改框架 | 影响全部下游(剧本/分镜/资产) | 全量重走受影响部分 |
| 改声音锚 | 引用该锚的全部镜头重生成(仅音轨层?待实测:需整镜重生成) | 重做 |

### 证据 log(log.md + log.jsonl)

每次产出追加一条:`{时间, 类型(资产/剧本/分镜/镜头/任务/验收/成本), 产出物路径, 关键参数, 决策理由, 版本, 成本(usage), 结果(PASS/FAIL+原因)}`。

## 9. 约束与依赖

- API key:`scripts/lib/env.js` 读取 `.env` 的 `MINIMAX_API_KEY`
- ffmpeg:v1 仅抽帧与 regeneration 前规格检查(教程 §7.5 抽帧命令);768P 成片**不二次编码**,直接 regeneration
- H3 单价:教程估算 2K 0.8 元/秒,768P 未知 → **以实测为准**(§0),成本 gate 用可配置常量
- 声音锚:TTS 无 duration 参数,按目标时长反推字数;单段 ≥2s(拼接/padding);按情绪分档
- **双轨声音**:A 轨 = 每镜 r2va 带 reference_audio 声音锚(待实测);B 轨 = 每镜台词 TTS 合成确定性对白(固定 voice_id);A 轨不合格 → 单镜 B 轨替换音轨(ffmpeg 单文件)
- 音色来源:系统音色(无需认证);克隆/设计音色需企业认证(账号待核实,未认证用系统音色)
- 参考音频:每镜 ≤3 段、每段 2-15s、总 ≤15s;同镜有台词角色 ≤ 3
- 参考图:每镜 ≤4 张(预算内,≤9 上限留余量);统一 9:16
- ratio:按模式规则(§2);资产统一 9:16 保证 r2va 竖屏
- 任务仅保留 7 天(query/list),成片须及时下载落盘;delete 按状态可用
- 文件上传有效期 7 天:`file_id` 过期在**前置校验**中检测并重传更新引用
- Context-IR 为黑盒(官方不开放实现):输出须过意图校验,失败走手动 fallback
- regeneration 规格:音轨存在 / 24fps / 宽高被 32 整除 / 面积≤768×1344 / 帧数∈{107+17k};不符合 → 裁剪(接受风险)/ 放弃 / 重生成,不转码
- 抽帧审用 Claude 原生视觉(不依赖 MiniMax vision,无公开 REST)
- 重试熔断:每镜 ≤3 次;集级预算熔断:超限暂停人工裁决
- 版权:所有参考图禁用真人/明星脸
- 参考音频计费:按 input_seconds 计入成本预估
- 语音质量:台词中文原文(不英译),提示词模板声明"中文台词"
