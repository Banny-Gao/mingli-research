# 短剧角色一致性用"双轨声音"方案:A 轨 r2va 参考音频锁声(待实测)+ B 轨 TTS 确定性对白(官方背书)

H3 生成视频时音轨随机,没有"角色音色锁定"参数,同角色跨镜声线会漂移。因此声音一致性走**双轨**:

- **A 轨(主,待实测假设)**:每镜 r2va 出片时带 `reference_audio` 声音锚(角色标准对白音频),让 H3 自带音轨贴合角色音色 + `reference_image` 锁脸 + 可选 `reference_video` 动作接续。官方只定义 `reference_audio` 是"参考音频",**未承诺锁音色或影响台词内容**——样镜验证必须实测(同锚不同台词音色是否一致、是否复读锚文本、H3 输出是否自带音轨)。
- **B 轨(确定性,官方背书)**:用 `speech-t2a-http`(固定 `voice_id`)为**每镜台词**合成独立对白音频——音色与文本 100% 确定。v1 即生效:样镜对比 A/B 轨,若 A 轨音色/台词不可接受,单镜用 B 轨音频 ffmpeg 替换 H3 音轨(单文件操作,非剪辑);整集统一配音是 v2 的自然延伸,不再依赖 A 轨成败。

音色来源分层:① v1 用 `speech-2.8-hd` **系统音色**(`mmx speech voices` 可列,40+ 语言,无需认证);② 音色克隆(`voice-cloning-uploadcloneaudio` + `voice-cloning-clone`,上传角色原声复刻专属音色)与音色设计(`voice-design-design`,文字描述生成音色)官方标注**需个人+企业认证**,认证后启用,生成专属 `voice_id`,7 天内首次 TTS 调用生效。

权衡:r2va 的 `reference_*` 与 i2va 的 `first_frame/last_frame` 互斥(API 硬约束),放弃首帧图锁画面、改为参考图锁脸。双轨的代价是每镜多一次 TTS 调用(按字符计费,便宜)+ 可能的一次音轨替换。
