# 短剧 skill v1 范围止于"单镜成片 + 768P→2K regeneration",后期剪辑/进阶一致性/批量化留 v2

v1 覆盖:想法 → 整体框架 → 选 voice_id → 角色/声音圣经 → 资产验收 → 单集剧本 → 分镜 → 本集资产生成 → 前置校验 → 成本 gate → 样镜子循环 → Context-IR 增强 → r2va 出片 → 成片验收 → 按因分流重试(熔断)→ regeneration 2K(可选开关,含独立 gate 与抽验)→ 集级复盘,以及补丁模式(受影响面计算表)、本剧共享资产、结构化证据 log。v2 展望完整清单见 docs/short-drama-create-design.md §6。

为什么这么切:(1) 降重做率的核心在出片前的校验与一致性,剪辑是纯机械工作,后置不重构;(2) BGM 与剪辑绑定(混音/ducking),单镜阶段 H3 自带音轨够用;(3) 同框/FaceFusion/LoRA 依赖 v2 的拼接与批量化能力,前置无收益;(4) 跨剧 manifest、自由指令、发布复盘等依赖先有真实使用场景,不搞机制先行;(5) 768P→2K 提前到 v1(降成本利器,草稿试错便宜),但以"待实测假设"为前提,样镜验证是关口。
