# 前置校验规则集 + 分镜表字段规范 + 受影响面计算表

> 对应设计文档 §8。这是"降低单条视频重做率"的核心(需求 5)。校验在**各关键点各跑一次**(设计决策 10),不是每步全量跑。

## 1. 分镜表字段规范(episode.md 内 Markdown 表格)

| 字段 | 必填 | 约束 |
|---|---|---|
| 镜号 | ✅ | shot_01, shot_02, ...(连续) |
| 场景 | ✅ | 引用本集或共享场景资产 id |
| 人物 | ✅ | 角色 id(引用角色圣经);空镜填 `-` |
| 动作 | ✅ | 具体动作/微表情 |
| 台词 | 条件 | 有对白才填;中文原文(不英译);与人物绑定 |
| 镜头语言 | ✅ | 特写/中景/远景/俯拍/跟拍 |
| 光影 | ✅ | 光源/色调/氛围 |
| 音效 | 条件 | 环境音/SFX 提示 |
| 时长 | ✅ | 4-15 整数秒 |
| 模式 | ✅ | r2va(有声对话)/ t2va(空镜)/ i2va(无台词首帧图) |
| 优先级 | ✅ | P0(开场/反转/结尾)/ P1(普通对话)/ P2(空镜/远景) |
| 声音锚 | 条件 | 有台词必填:引用的角色声音锚(按情绪段,如 `林念安·怒`) |
| 动作接续 | 条件 | 是否引用前镜成片作 reference_video(yes/no) |
| 比例 | ✅ | 默认 9:16;t2va 必填不能 adaptive;i2va 强制 adaptive;r2va 由参考图决定 |
| 分辨率 | ✅ | 768P(草稿)/ 2K(regeneration 后);默认 768P |
| 状态 | ✅ | 待生成/已生成/验收中/PASS/FAIL(原因)/2K 已抽验 |

## 2. 前置校验(步骤 6,分镜定稿后跑)

### 2.1 完整性
- [ ] 每镜字段齐全(按上表必填项)
- [ ] 台词与人物匹配(台词在对应角色的圣经/剧本中出现)
- [ ] 声音锚引用有效(有台词镜必填;引用的锚存在且情绪匹配台词情绪)
- [ ] 镜号连续无重复

### 2.2 一致性
- [ ] 角色 ref 全部引用(分镜用到的角色都在角色圣经中有图)
- [ ] 服装/场景引用齐全(换装角色有对应服装锚;场景在资产中存在)
- [ ] 同框约束:有台词角色 ≤ 3;i2va 仅无台词镜头
- [ ] 台词语言统一中文(不英译,防 H3 识别错)

### 2.3 可生成性
- [ ] 参考图文件存在(本地或 mm_file:// 引用有效)
- [ ] 文件 ≤ 规格(图 30MB/视频 50MB/音频 15MB)
- [ ] 时长合法(4-15 整数秒)
- [ ] 比例按模式(t2va 必填非 adaptive;i2va 强制 adaptive;r2va 默认 adaptive)
- [ ] 参考音频:≤3 段、每段 2-15s、总时长 ≤15s
- [ ] 参考图:≤4 张(预算内,≤9 上限留余量)
- [ ] **file_id 有效性**:7 天过期则重传并更新引用(见 §4)
- [ ] 版权:参考图不用真人/明星脸

## 3. 各关键点校验(触发时机)

| 步骤 | 校验内容 | 通过后 |
|---|---|---|
| 2 资产验收 | 角色 LLM 审(脸)+ 人工;声音仅人工听;规格 | 黄金锚 + 定稿锁 |
| 6 前置校验 | 上表全部 | GATE:人工确认 ready |
| 8 样镜 | 黄金锚对比/风格/一致性/锁声实测 | 定质量基线 → 批量 |
| 11 成片验收 | 抽帧审 + 跨镜 + 人工听声 + B 轨对比 | PASS/FAIL 分流 |
| 12 regeneration 预检 | 音轨/24fps/32 整除/面积/帧数 | 提交 2K |

## 4. file_id 有效期管理

- 上传的 `mm_file://{file_id}` 7 天过期
- 前置校验(步骤 6)检测:校验本地资产文件 mtime 距上次上传 > 7 天 → 标记"需重传"
- 生成请求前统一重传并更新引用
- 跨会话恢复:启动时检查 assets/ 下资产的 file_id 记录(evidence/ 中),过期即重传

## 5. 受影响面计算表(补丁模式)

| 变更类型 | 影响范围 | 处理 |
|---|---|---|
| 改台词 | 该镜重生成;声音锚文本与台词脱节 → 重生成该镜声音锚(如情绪段无匹配则重建) | 重做该镜 |
| 改场景 | 引用该场景的全部镜头 | 重做 + 场景资产重建 |
| 改道具 | 引用该道具的镜头 | 重做 |
| 改角色外貌 | 该角色全部已出镜头作废 + 相关声音锚 | **先确认废弃成本** |
| 改框架 | 影响全部下游(剧本/分镜/资产) | 全量重走受影响部分 |
| 改声音锚 | 引用该锚的全部镜头重生成(仅音轨层?待实测:需整镜重生成) | 重做 |
| 改 voice_id | 该角色全部 B 轨音频 + 声音锚 + 引用镜头 | 先确认废弃成本 |

## 6. regeneration 规格预检(步骤 12)

ffprobe 检查(用 `scripts/lib/h3-api/video.js` 的 `probeVideo`):
- [ ] 音轨存在(hasAudio=true)
- [ ] 24fps
- [ ] 宽高被 32 整除
- [ ] 面积 ≤ 768×1344
- [ ] 帧数 ∈ {107, 124, ..., 362}(每档递增 17 帧)

不满足 → 三选一:
1. 时长裁剪(接受内容风险)
2. 放弃该镜 regeneration,用 768P 直出
3. 重生成到合规时长

**不转码**——转码违背"原样提交原始输入"要求。
