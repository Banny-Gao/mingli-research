# 状态机详细步骤

> SKILL.md 的 14 步状态机的落地细节。每步:输入 → 处理 → 输出 → gate。GATE 分级:硬 gate(必须停,AskUserQuestion 确认)/ 软 checkpoint(可跳过,列表确认)。

## GATE 分级

| 级别 | 步骤 | 说明 |
|---|---|---|
| 硬 gate | 0 想法 / 1 框架 / 4 分镜 / 6 前置校验 / 7 成本 | 必须人工确认才继续 |
| 软 checkpoint | 2 资产验收 / 11 成片验收 | P0 必停,P1/P2 可批量确认 |

## Step 0 — 想法 Idea

**输入**:用户的一句话想法(题材/受众/钩子/集数)
**处理**:
1. AskUserQuestion 确认:题材偏好、目标受众、情绪钩子、集数规划
2. 生成 3 个选题建议(带爆款指数),用户挑 1 个或自定义
**输出**:选定想法(一句话核心冲突)
**GATE**(硬):确认想法 → 进 Step 1

## Step 1 — 整体框架 series.md

**输入**:选定想法
**处理**:生成 `short-dramas/{slug}/series.md`:
- 一句话核心冲突
- 主角设定(2 句话/角色)
- 分集主线(每集一句话)
- 目标受众 / 集数规划 / 爆款指数
**输出**:`short-dramas/{slug}/series.md` + evidence log
**GATE**(硬):框架确认。之后每集以它为唯一依据,不重写。

## Step 2 — 角色圣经 + 声音圣经(剧级资产)

**输入**:框架中的主角列表
**处理**:
1. **选 voice_id**(软 checkpoint,需创作者参与):为每角色从 `speech-2.8-hd` 系统音色中选(按性别/年龄/气质;`mmx speech voices --language chinese` 可列)。这是创作决策,LLM 给建议 + 用户确认。
2. **角色参考图**(image-01 文生图):每角色核心锚(正面/45°/全身)+ 表情锚(哭/笑/怒/惊)+ 服装锚(每套 1 张)
3. **声音锚 A 轨**(TTS):LLM 按人设写"角色标志性台词集"(与剧本解耦),按情绪分档(中性/哭/怒/惊),每段 ≥2s(按目标时长反推字数,短句拼接/padding)
4. 版权检查:不用真人/明星脸
5. 规格校验(文件/比例/大小/9:16)
**校验**:见 rules/validation.md §2.1-2.3 的资产相关项
**GATE 资产验收**(软):
- 角色 = LLM 审(Claude 视觉,脸是否如人设)+ 人工确认
- 声音 = 仅人工听(LLM 无法审音频)
- 通过 → 挑最佳为**黄金锚**(每角色 1 张)→ **定稿锁 LOCKED**
**GATE**(软):角色一致性人工确认。之后改外貌必须先确认废弃成本。

## Step 3 — 单集剧本 episode.md

**输入**:框架 + 前情提要(读已完成的集)
**处理**:
1. 生成单集剧本(875-1100 字台词+场景描写,5 分钟;开篇钩子→冲突→升级→结尾钩子;每 15 秒转折;金句;镜头建议)
2. 自由对话迭代(不限轮,每轮改一个维度:节奏/台词/人设/钩子/结构)
3. **短剧感自检**(LLM):钩子强度 / 转折密度 / 台词口语化 / 结尾钩子
**输出**:`episodes/ep{NN}/episode.md`(剧本部分)+ evidence log(每次迭代追加)
**GATE**(硬):剧本确认 → 进 Step 4

## Step 4 — 分镜表

**输入**:定稿剧本
**处理**:
1. 拆解为镜头(5 分钟 ≈ 25-30 镜;每镜 4-15s;字段见 validation.md §1)
2. 每镜指定模式(r2va/t2va/i2va)+ 优先级 + 声音锚(按台词情绪选段)
3. 同框约束:有台词角色 ≤ 3;对话用正反打;i2va 仅无台词
4. 状态字段初始化为"待生成"
**输出**:`episodes/ep{NN}/episode.md`(分镜部分)
**GATE**(硬):分镜确认 → 进 Step 5

## Step 5 — 本集资产生成

**输入**:分镜表
**处理**:
1. 场景参考图(文生图,无人空镜,统一 9:16)
2. 道具 / 服装锚(按分镜需要)
3. 规格校验
**输出**:`episodes/ep{NN}/assets/` + evidence log
(无独立 gate,规格校验通过即继续)

## Step 6 — 前置校验 ⭐

**输入**:分镜表 + 全部资产
**处理**:跑 validation.md §2 全部校验项(完整性/一致性/可生成性/file_id 有效期/版权)
**输出**:校验报告(问题项列表)
**GATE**(硬):人工确认 ready。**不通过不进入生成**——这是降重做率的第一道关。

## Step 7 — 成本预估 gate ⭐

**输入**:分镜表(本批要生成的镜头)
**处理**:
1. 本批镜头数 × 时长 × 单价(768P/2K 实测值,可配置常量)
2. 已用预算(本集/本剧)
3. 检查重试熔断(每镜 ≤3 次)与集级预算
**GATE**(硬):确认后才生成。

## Step 8 — 样镜验证 ⭐ 子循环(每集首个 P0)

**输入**:分镜表中首个 P0 镜头
**处理**(走完整链路):
1. Context-IR 增强(步骤 9 流程)
2. 生成(768P,步骤 10 流程)
3. 验收(步骤 11 流程)
4. **锁声实测 ⭐**:A 轨音色是否一致?未复读锚文本?台词内容正确?
**通过** → 定质量基线 → 批量铺开(其余镜头按此模板)
**FAIL** → 调提示词/资产,重试样镜;锁声失败 → 回决策层(ADR 0002 降级:B 轨替换音轨)

## Step 9 — Context-IR 提示词增强(每镜)

**输入**:分镜 + 参考图/音频
**处理**:
1. 调 `createContextIr({content, duration, ratio})` → 轮询 → 取 `content.prompt`
2. **意图校验 ⭐**(LLM):增强结果是否忠实原分镜(镜头/台词/人物不变)
3. 失败/超时/跑偏 → **fallback**:手动模板写提示词(rules/prompts.md)
**输出**:最终提示词(三段式:分镜描述/环境音/配乐)+ 存 `non_diegetic_music` 供 v2 BGM
(无独立 gate,意图校验通过即继续)

## Step 10 — r2va 视频生成 ⭐

**输入**:分镜 + 增强提示词 + 资产
**处理**(每镜):
1. 按模式组请求:
   - r2va 有声对话:reference_image(锁脸)+ reference_audio(A 轨锚锁声)+ 可选 reference_video(动作接续)
   - t2va 空镜:仅文本
   - i2va 无台词:首帧图 + 文本
2. **B 轨 ⭐**:每镜台词 TTS 合成确定性对白(固定 voice_id),存 `assets/audio/`
3. 调 `createVideo()` → 轮询 `waitForVideo()` → 下载落盘 `shots/shot_XX_v{NN}.mp4`
4. **请求快照保存 ⭐**(完整请求体 → `evidence/` JSON,供 regeneration/补丁复用)
**输出**:成片 + B 轨音频 + 请求快照
(无独立 gate)

## Step 11 — 成片验收 ⭐

**输入**:成片 + 黄金锚 + 分镜
**处理**:
1. 抽帧(ffmpeg,`extractFrames`)
2. **LLM 抽帧审**(Claude 原生视觉):黄金锚对比(脸/服装/标志)+ checklist(validation.md §2 的验收项)
3. **跨镜对比 ⭐**:带 1-2 张已 PASS 前镜帧,检查"同一人"
4. **人工听声 ⭐**:对白清晰/音画同步/音效/音色漂移(LLM 无法审音频)
5. **B 轨对比 ⭐**:A 轨(H3 自带)vs B 轨(TTS 确定性)——A 轨不合格 → 单镜用 B 轨替换音轨(ffmpeg 单文件,非剪辑)
**GATE**(软):P0 必停人工确认;P1/P2 可批量确认
**PASS** → 分镜表状态更新 + evidence log
**FAIL** → 按因分流(每镜 ≤3 次):
- 提示词问题 → 改提示词 → 回 Step 9
- 参考图问题 → 修资产 → 回 Step 2/5
- 敏感内容 → 改描述 → 回 Step 9
- 规格问题 → 修参数 → 回 Step 10
- 音频/音色问题 ⭐ → 检查锚与台词 → 回 Step 2/3/9
**证据**:失败原因入 log(复盘回放)

## Step 12 — regeneration 2K ⭐(可选开关,本批全 PASS 后)

**输入**:本批全部 PASS 的 768P 成片
**处理**:
1. 触发:本批全 PASS 且启用 2K
2. 规格预检(probeVideo,validation.md §6)——不满足三选一(裁剪/放弃/重生成,**不转码**)
3. 2K 成本 gate(独立,区别于草稿成本)
4. 提交(`createRegeneration`,原样输入 + 最终 prompt,768P 不二次编码)→ 轮询 → 落盘
5. **2K 抽验 ⭐**(轻量:黄金锚 + 关键帧 + 人工瞄一眼)
**输出**:2K 成片 + evidence log

## Step 13 — 集级复盘 ⭐(每集收尾)

**处理**:
1. 成本汇总(本集/累计,含 regeneration)
2. 重做率(FAIL 次数/总生成次数)
3. 失败镜头分布(原因分类,含音频/音色类)
4. 经验教训 → 入 evidence
**输出**:复盘记录(evidence/log)

## 补丁模式(编辑)

- 创作者改剧本/分镜/资产 → 按 validation.md §5 受影响面计算表 → 只重做受影响下游
- 角色外貌改动 → **先确认废弃成本**(该角色全部已出镜头作废)
- 声音锚重生成触发:改台词 → 重生成该镜锚;改 voice_id → 该角色全部 B 轨 + 锚 + 引用镜头
- 请求快照让补丁可复用原始参数,不重新推导

## 跨会话恢复

1. 启动读 `short-dramas/{slug}/series.md`(框架)+ `episodes/`(进度)+ `evidence/log`(历史)
2. 从分镜表状态字段推断进行到哪一步(待生成/已生成/验收中/PASS/FAIL)
3. 检查 assets/ 的 file_id 是否过期(>7 天重传)
4. 从上次停下的步骤继续
