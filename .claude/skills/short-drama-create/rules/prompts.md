# 提示词模板集

> 剧本/分镜/提示词/Context-IR/验收的 LLM 模板。短剧 skill 主 agent 是 Claude(自身视觉/文本),这些模板喂给 Claude 生成,而非 MiniMax(除了 H3 视频提示词)。

## 1. 选题生成

```
你是爆款短剧编剧,擅长 3-6 分钟竖屏短剧(抖音/快手/红果风格)。
基于以下输入生成 3 个选题:
- 题材偏好:{偏好}
- 目标受众:{受众}
- 情绪钩子:{钩子}
- 集数规划:{集数}集,每集{时长}分钟
每集结尾必须留强钩子(悬念/反转/情感冲击)。
每个选题:1) 一句话核心冲突 2) 主角设定(2 句) 3) 5 集内主线走向 4) 预估爆款指数(1-10)和理由
```

## 2. 整体框架(series.md)

```
基于选题 {X},生成整体框架 series.md:
- 一句话核心冲突
- 主角设定(2 句话/角色,含视觉描述:外貌/年龄/气质/常穿服装/标志性细节)
- 分集主线(每集一句话:本集冲突/钩子/下一集引子)
- 目标受众 / 集数规划 / 爆款指数(1-10)+ 理由
这是全剧唯一框架源,后续所有集以此为依据,不重写。
```

## 3. 单集剧本(episode.md 剧本部分)

```
基于框架 + 前情提要,生成第 {N} 集剧本。
- 时长:5 分钟 ≈ 875-1100 字台词+场景描写
- 结构:开篇钩子(30s 内)→ 冲突建立(2min)→ 升级对抗(2min)→ 结尾钩子(30s)
- 节奏:每 15 秒一个情绪/情节转折,5 分钟内 20+ 转折
- 情节:2-3 个核心冲突 + 1 个大反转/钩子
- 结尾:卡在最揪心/最反转的一刻
- 台词:口语化、短句为主,符合移动端无声播放也能看懂;中文原文(不英译)
- 给出 5-8 个"金句"(可截屏传播的高情绪台词)
- 标注:哪些台词需要慢镜头/特写
- 拆分:4-5 个【场景块】,每块 1 分钟

输出格式:
【场景 1 - 开篇钩子】地点/时间/人物 (0:00-0:30)
[动作描述]
角色A:台词
【情绪标记】:xxx
【镜头建议】:特写/中景/远景
...
```

**迭代原则**:每轮只改一个维度(节奏/台词/人设/钩子/结构),自由对话不限轮。

## 4. 短剧感自检(剧本定稿前)

```
审查以下剧本,逐项评分(1-5)并给一句修改建议:
1. 开场钩子强度(30s 内是否抓人)
2. 转折密度(是否每 15 秒有情绪/情节转折)
3. 台词口语化(是否像人说话,短句为主)
4. 结尾钩子(是否逼用户看下一集)
5. 金句数量(是否够截屏传播)
总分 < 18 → 指出最弱项,建议改哪一维度。
```

## 5. 分镜表(episode.md 分镜部分)

```
你是资深短剧分镜师,把以下剧本拆解为 H3 视频生成用的分镜表。

H3 限制:
- 单次生成 4-15 秒
- 同框有台词角色 ≤ 3(对话用正反打,避免同框混脸)
- i2va 仅无台词镜头(首帧图);有声对话用 r2va(参考图锁脸+参考音频锁声);空镜用 t2va
- 9:16 竖屏

每镜字段(见 rules/validation.md §1):
镜号,场景,人物,动作,台词(中文原文),镜头语言,光影,音效,时长(4-15s),
模式(r2va/t2va/i2va),优先级(P0/P1/P2),声音锚(按台词情绪:中性/哭/怒/惊),
动作接续(yes/no),比例(9:16),分辨率(768P),状态(待生成)

5 分钟一集约 25-30 镜;开场 30s = 4-5 镜每镜爆点;结尾 30s 大动作(特写+慢动作+强音效)。
```

## 6. 角色视觉描述(角色圣经)

```
为短剧主角「{角色}」写视觉描述:
- 年龄/性别/东亚特征/发型/脸型/气质
- 常穿服装(详细)
- 标志性细节(痣/疤痕/首饰位置)——后续所有镜头必带
- 输出 6 段不同角度/表情/光线的英文 prompt 用于 H3 文生图:
  正面中性/45° 微笑/侧面冷光/全身站姿/愤怒/哭泣
  每段含:8k, highly detailed, photorealistic, cinematic lighting, sharp focus, 9:16
```

## 7. 角色标志性台词集(声音锚文本)

```
为短剧主角「{角色}」写 4 句标志性台词(按情绪分档),用于 TTS 生成声音锚:
- 中性(1 句):角色日常口吻
- 哭(1 句):情绪爆发时
- 怒(1 句):冲突对抗时
- 惊(1 句):意外震惊时
每句 15-30 字,口语化,体现角色性格。TTS 后每段 ≥2 秒(不足则拼接/padding)。
```

## 8. H3 视频提示词(模板 + Context-IR 增强)

**模板(手动 fallback 用)**:

```
[Quality] cinematic, 9:16 vertical, 768P, 24fps, photorealistic, sharp focus

[Subject] Character {ref_id}, {gender}, {age}, {appearance}, {outfit}, {signature: mole/scar/earring}

[Action] {具体动作/微表情/中文台词}

[Camera] {镜头:ECU/CU/MS/WS}, {运镜:static/slow push-in/handheld}, {角度}

[Lighting] {光源/色调/氛围}

[Audio] 对白:"{中文台词}" / 音效:{SFX} / 环境音:{Ambient}
```

**Context-IR**(主路径):每镜调 `createContextIr`,增强后三段式提示词(分镜描述/环境音/配乐)。**意图校验**:LLM 确认忠实原分镜(镜头/台词/人物不变)。失败/跑偏 → 手动模板 fallback。

## 9. 成片验收(LLM 抽帧审,Claude 原生视觉)

```
对比参考图(黄金锚)与生成视频的抽帧,逐项判定:
1. 角色脸是否一致(脸型/五官/发型)
2. 服装是否与场景设定一致
3. 标志性配饰是否在位(痣/耳钉/项链)
4. 动作是否自然(无鬼畜/变形)
5. 画面是否清晰(无模糊/噪点)
6. 是否 9:16 竖屏
每项 PASS/FAIL + 1 句原因。任一 FAIL → 判定 FAIL,给出原因分类(提示词/参考图/敏感/规格)。
```

**跨镜对比**(加项):再带 1-2 张已 PASS 前镜帧,判定"同角色任意两镜,普通人能认出是同一个人"。

## 10. 音频验收提示词(人工听声,LLM 无法审音频)

人工听成片音频,检查:
- [ ] 对白清晰可听,无 AI 错字
- [ ] 台词内容与分镜一致(未复读锚文本)
- [ ] 音画同步(嘴型匹配)
- [ ] 音效/环境音是否符合分镜
- [ ] 音色是否与声音锚一致(不漂移)
A 轨不合格 → 单镜用 B 轨(TTS 确定性音频)替换音轨。
