# short-drama-create 短剧创作技能(主入口)

交互式使用 MiniMax H3 创作竖屏短剧。设计文档:`docs/short-drama-create-design.md`(v4)。术语表:`CONTEXT.md`。ADR:`docs/adr/0001-0004`。

## 调用方式

用户输入 `/short-drama-create` 起手。可选带参数 `/short-drama-create {new|continue}`:
- `new`:新建一部剧
- `continue`:继续既有剧(从 `short-dramas/{slug}/series.md` + `episodes/` 恢复)

## 14 步状态机

```
[0] 想法 Idea
    ├─ 输入:题材偏好/目标受众/情绪钩子/集数规划
    └─ GATE:确认想法

[1] 整体框架 series.md ── 每部剧唯一框架源
    ├─ 一句话核心冲突/主角设定/分集主线/爆款指数
    └─ GATE:框架确认

[2] 角色圣经 + 声音圣经 ── 剧级资产,一次投入全剧复用
    ├─ 为每角色选 voice_id ⭐(系统音色;克隆/设计留认证后)
    ├─ 文生图 image-01 → 角色参考图(核心锚/表情锚/服装锚)
    ├─ TTS → 声音锚(A 轨:按情绪分档,每段≥2s;锚文本=LLM 按人设写"标志性台词集")
    ├─ 版权检查:禁用真人/明星脸
    ├─ 校验:规格(文件/比例/大小/9:16)
    ├─ 资产验收 ⭐:角色=LLM 审(脸)+人工;声音=仅人工听
    ├─ 挑最佳 → 黄金锚(每角色 1 张,后续所有验收基准)
    └─ 定稿锁 LOCKED ⭐(改外貌须确认废弃成本)

[3] 单集剧本 episode.md ── 基于框架+前面剧情
    ├─ 结构:开篇钩子→冲突建立→升级对抗→结尾钩子
    ├─ 迭代:自由对话不限轮(每轮改一个维度)
    ├─ 短剧感自检 ⭐(钩子/转折密度/台词口语化/结尾钩子)
    └─ 证据:每次产出自动追加 evidence/log

[4] 分镜表 ── episode.md 内(字段见 rules/validation.md)
    ├─ 拆解:5 分钟≈25-30 镜/每镜 4-15s
    ├─ 声音锚引用(按台词情绪选段)
    ├─ 同框约束 ⭐:有台词角色≤3;i2va 仅无台词镜头
    └─ 状态字段 ⭐:待生成/已生成/验收中/PASS/FAIL(文件即状态)

[5] 本集资产生成
    ├─ 场景参考图(文生图,无人空镜,统一 9:16)
    ├─ 道具/服装锚
    └─ 校验:规格校验

[6] 前置校验 ⭐(降重做率核心)
    ├─ 完整性:字段齐全/台词匹配角色/声音锚引用有效
    ├─ 一致性:角色 ref 全引用/服装场景齐全/同框约束
    ├─ 可生成性:文件存在/≤规格/时长比例合法/i2va 无台词/ratio 按模式/参考音频≤3段·每段2-15s·总≤15s
    ├─ file_id 有效性 ⭐:7 天过期则重传更新引用
    └─ GATE:人工确认 ready → 才开始生成

[7] 成本预估 gate ⭐(每批)
    ├─ 本批镜头×时长×单价(768P/2K 实测值)
    ├─ 已用预算 + 重试熔断(每镜≤3 次)+ 集级预算
    └─ 确认后才生成

[8] 样镜验证 ⭐ 子循环(每集首个 P0,走完整链路)
    └─ 选首个 P0 → Context-IR → 生成(768P)→ 验收
        ├─ 验收项:黄金锚对比/提示词风格/一致性/锁声实测⭐(音色一致?未复读锚文本?台词正确?)
        ├─ 通过 → 定质量基线 → 批量铺开
        └─ FAIL → 调提示词/资产;锁声失败 → 回决策层

[9] Context-IR 提示词增强(每镜)
    ├─ 输入:分镜+参考图/音频
    ├─ 输出:三段式增强提示词(分镜描述/环境音/配乐)
    ├─ 意图校验 ⭐:确认忠实原分镜(镜头/台词/人物不变)
    ├─ fallback ⭐:失败/跑偏 → 手动模板写提示词
    └─ non_diegetic_music ┄┄(存证据,供 v2 BGM)

[10] r2va 视频生成 ⭐(出片核心)
    ├─ 有声对话镜:必带 reference_image 锁脸+reference_audio 锁声(A 轨)
    ├─ t2va 空镜:仅文本(不带参考图,防污染)
    ├─ i2va 无台词镜:仅首帧图+文本(不带音频锁)
    ├─ B 轨 ⭐:每镜台词 TTS 合成确定性对白(固定 voice_id),存 assets/audio/
    ├─ 可选:reference_video 前镜成片(动作接续)
    ├─ 流程:创建任务→轮询→下载落盘 shots/(v0/v1/...)
    ├─ 请求快照保存 ⭐(完整请求体→供 regeneration/补丁复用)
    └─ 版本命名:shot_XX_v{NN}.mp4

[11] 成片验收 ⭐
    ├─ LLM 抽帧审(Claude 原生视觉):黄金锚对比/服装/标志/checklist
    ├─ 跨镜对比 ⭐:带 1-2 张已 PASS 前镜帧,检查"同一人"
    ├─ 人工听声 ⭐:对白清晰/音画同步/音效/音色漂移
    ├─ B 轨对比 ⭐:A 轨(H3 自带)vs B 轨(TTS),A 轨不合格→单镜 B 轨替换音轨
    ├─ PASS → 分镜表状态更新+入 evidence
    └─ FAIL → 按因分流(每镜≤3 次):提示词/参考图/敏感/规格/音频音色

[12] regeneration 2K ⭐(可选开关,本批全 PASS 后)
    ├─ 触发:本批全 PASS 且启用 2K
    ├─ 规格预检 ⭐(ffprobe):音轨/24fps/32 整除/面积≤768×1344/帧数∈{107+17k}
    ├─ 不满足→裁剪(接受风险)/放弃/重生成(不转码)
    ├─ 2K 成本 gate(独立)
    ├─ 提交(原样输入+最终 prompt,不二次编码)→轮询→落盘
    └─ 2K 抽验 ⭐(轻量:黄金锚+关键帧+人工瞄一眼)

[13] 集级复盘 ⭐(每集收尾)
    ├─ 成本汇总(含 regeneration)
    ├─ 重做率(FAIL/总生成)
    ├─ 失败镜头分布(原因分类,含音频音色)
    └─ 经验教训 → 入 evidence

[14] 剪辑 ┄┄ v2 展望(EDL/ffmpeg 拼接/BGM/整集配音/多平台导出)
```

> v1 实线,`┄┄` v2。补丁模式:任意上游改动 → 受影响面计算表(rules/validation.md)→ 只重做受影响下游;角色外貌改动须先确认废弃成本。

## 双轨声音(ADR 0002)

- **A 轨**:每镜 r2va 带 `reference_audio` 声音锚(角色标准对白音频),让 H3 自带音轨贴合角色音色 + `reference_image` 锁脸。**待实测假设**——样镜验证必须实测(音色一致?未复读锚文本?)
- **B 轨**(确定性):每镜台词用 `speech-2.8-hd` 固定 `voice_id` 合成独立对白音频,音色+文本 100% 确定。A 轨不合格 → 单镜 B 轨替换音轨(ffmpeg 单文件)
- 音色来源:v1 系统音色;克隆/设计(需企业认证)留认证后

## 待实测假设(§0,样镜验证关口)

| 假设 | 若失败 |
|---|---|
| reference_audio 锁音色 | A 轨降级:单镜 B 轨替换音轨 |
| 不复读锚文本 | 同上+锚文本同源 |
| H3 输出自带音轨 | regeneration 不可用,768P 直出(已实测✅有音轨) |
| 768P 单价 | 成本 gate 用实测值 |

## 成本熔断(需求 5)

- 每批出片前成本预估 gate
- 每镜重试 ≤3 次
- 集级预算超限 → 暂停人工裁决
- `usage` 入证据;集级复盘

## 错误处理总览

| 失败点 | 处置 |
|---|---|
| 缺 API key | 启动报错 + 打印配置指引(LLM_API_KEY / MINIMAX_H3_API_KEY) |
| H3 任务 failed | 读 error.code/message → 按因分流重试(≤3 次) |
| Context-IR 失败/跑偏 | 意图校验 → 手动模板 fallback |
| 前置校验不通过 | 报告问题项,不进入生成 |
| 样镜锁声验证失败 | 回决策层(ADR 0002 降级:B 轨替换音轨) |
| 成本超预算 | 熔断暂停,人工裁决 |
| 补丁改角色外貌 | 先确认废弃成本 |
| 7 天任务过期 | 成片已落盘,任务记录可删 |
